# CIFAR 10

## Overview
This project involves classifying CIFAR-10 images using machine learning techniques. The goal is to develop and evaluate models for multi-class image classification on the CIFAR-10 dataset.

## Quick Start
1. Install dependencies: `pip install tensorflow matplotlib numpy pandas scikit-learn seaborn opendatasets`
2. Run the notebook cells sequentially to train and evaluate models.
3. Visualize results and generate reports.

## Directory Structure
- `Notebooks/`: Contains Jupyter notebooks for experimentation and reporting
- `Reports/`: Stores detailed project reports and analysis
- `Utils/`: Utility scripts for data handling and preprocessing

## Usage
Refer to the Jupyter notebooks for end-to-end workflows. Execute cells in sequence for reproducible results.
