# Cancer Classification

## Overview
This project applies transfer learning to classify brain MRI images into tumor categories. Using MobileNetV2 as a base model, the system achieves high accuracy in distinguishing between different types of brain tumors.

## Quick Start
1. Install dependencies: `pip install tensorflow matplotlib numpy scipy scikit-learn seaborn opendatasets`
2. Run the notebook sequentially to train the classification model.
3. Evaluate results using the provided report and visualizations.

## Directory Structure
- `Notebooks/`: Contains Jupyter notebooks for model training and evaluation
- `Reports/`: Stores detailed project reports, results, and analysis
- `Utils/`: Utility scripts for data preprocessing and augmentation

## Usage
Execute notebook cells in order for reproducible training and validation. Output includes accuracy metrics and visual assessments.
