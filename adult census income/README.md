# Adult Census Income Prediction

## Overview
This project develops a machine learning model to predict whether individuals earn more than $50K per year based on census data. It utilizes the Adult Census Income dataset and various classification algorithms to address the predictive analytics task.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Run data preprocessing pipeline: `python adult census income/adult census income/adult_income_pipeline.py preprocess`
3. Train model: `python adult census income/adult census income/adult_income_pipeline.py train`
4. Evaluate model: `python adult census income/adult census income/adult_income_pipeline.py evaluate`

## Directory Structure
- `data/`: Contains raw and processed census data
- `models/`: Trained model artifacts and checkpoints
- `scripts/`: Pipeline scripts for data processing and modeling
- `references/`: Documentation and research references

## Usage
Execute pipeline stages sequentially to preprocess data, train models, and evaluate performance. Results include accuracy metrics and visualization outputs.
